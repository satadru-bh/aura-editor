# Aura App Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clean up obsolete project artifacts, set default dark theme and eliminate cheap saturated accent colors outside the text area, and overhaul the Windows installer to match the reference design with dark/light mode toggle.

**Architecture:** 
- Cleanup: Remove unneeded root screenshots, logs, old batch launchers, and stale heavy unpack directories.
- Theme refinement: Change default theme to `'dark'` in `src/App.tsx`; redefine `ringColor` and UI chrome CSS in `tailwind.config.js`, `src/index.css`, and components to use restrained monochromatic hierarchy instead of saturated accent rings/borders.
- Installer overhaul: Modernize `custom-installer/` into a 5-step wizard (`Welcome`, `Install Location`, `Options`, `Installing`, `Complete`) styled after the provided reference mockup, with complete Light/Dark mode support.

**Tech Stack:** React 19, TypeScript, Tailwind CSS, CodeMirror 6, Electron, Vitest

**Spec:** User request from 2026-11-09

## Global Constraints
- Do not break existing markdown editing, live plugins, or 29 passing unit tests.
- Maintain seamless cross-platform desktop/web behavior.
- Ensure all file paths and npm commands adapt properly for Windows (`npm.cmd` / `npx.cmd`).

## Review Focus
1. Default theme starts in dark mode for new users without clobbering existing stored user preferences.
2. No garish neon colored rings or outlines on modals, dialogs, toolbars, and inputs outside the text area.
3. Installer handles back/next navigation across all 5 steps properly.
4. Installer dark/light mode toggle works smoothly and updates the window aesthetics in real time.
5. All 29 unit tests pass and `npm.cmd run build` succeeds without TS or bundling errors.
